# Prompt Builder

Página simples (um único HTML, sem IA) que ajuda a escrever prompts melhores:

- Organiza sua mensagem em categorias (Objetivo, Contexto, Público, Formato, Tom, Restrições, Exemplos)
- Aponta o que está faltando e palavras vagas
- Monta o prompt final em inglês, em tópicos

Tradução: usa o tradutor embutido do navegador (Chrome 138+) quando disponível; opcionalmente, o serviço online MyMemory (desligado por padrão).

Para usar, abra `index.html` no navegador.
